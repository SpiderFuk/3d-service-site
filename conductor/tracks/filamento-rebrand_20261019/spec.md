## Summary

Roll out the printo "Filamento" visual identity across the whole site, replacing the old blue/Inter look and the old cube logo, without changing any behavior.

## Context

printo is a 3D printing service in Montevideo / Las Piedras whose main conversion funnel is browse services and models → quote via WhatsApp. One of the product goals is a modern, professional web presence. The current UI still uses a generic template look (primary `#3B82F6`, Inter, slate grays, cube GIF logo, "[PRINTO]" placeholder name) that does not match the new brand.

**Sources of truth:** `docs/brand.md`, `docs/tokens.json`, `static/brand/brand.css`, `tailwind.extend.snippet.js`, `static/brand/logo/`. **Reference for the intended look:** `REBRAND-PLAN.md`.

**Current state (2026-10-19):** brand docs already applied to `CLAUDE.md` and `conductor/product-guidelines.md` (commits `dbb9745`, `0c2b054`). Code is untouched: `tailwind.config.js`, `src/app.css`, `src/app.html` still use the old tokens. The brand kit (`docs/`, `static/brand/`, `REBRAND-PLAN.md`, `tailwind.extend.snippet.js`) is untracked in git.

## Motivation

The site still looks like a template and contradicts the new identity. Users need consistent, recognizable branding across the web, social previews and favicons. Accessibility also improves along the way (e.g. white text on WhatsApp green is only 1.9:1 contrast).

## Risk Assessment

- **Auto-deploy:** `main` and `develop` deploy to S3/CloudFront automatically. All work stays on `rebrand/filamento`; it reaches `develop` only through a PR after QA.
- **Global token change:** changing `primary`/`text`/`background` in Tailwind recolors every component at once. Intermediate commits (after Phase 1) may look inconsistent until Phases 3–5 land, which is acceptable on the branch.
- **Contrast pitfalls:** tomate/mantequilla/menta must never be text colors; `primary` hover states and WhatsApp green need checking.
- **Semantic colors:** blanket replacement of `blue-`/`amber-`/`red-` classes could break the out-of-service states or the real filament color values. These are explicitly excluded.
- **Three.js scene:** the background change in `sceneSetup.ts` and the logo placeholder must not affect lighting, camera or disposal.
- **Asset paths:** moving old logos could break references (including `onerror` fallbacks in Navbar). Grep before moving.
- **Tooling:** Playwright is not installed; it will be added as a devDependency (`@playwright/test`) with a small screenshot script for QA. Browser download may be slow or need system deps on WSL.
